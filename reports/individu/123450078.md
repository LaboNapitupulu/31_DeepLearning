# Draf laporan individu · Givaro Ananta (123450078)

## Komponen
Transformer. Transformer encoder dua lapis memproses 49 patch 32×32 untuk memprediksi empat kelas okupansi.

## Keputusan desain
Patch embedding dan empat head membatasi ukuran model. AdamW, dropout 0,1, dan weight decay digunakan pada konfigurasi awal. Normalisasi kanal dihitung dari data latih yang disediakan pemuat bersama.

## Kegagalan dan pelajaran
Pada pemrosesan awal, 96 dari 193 citra masuk ke jendela kondisi. Perbedaan
antara log rancangan dan okupansi aktual mendorong kurasi 160 citra dengan
label visual.

## Hasil
Run dataset kurasi dengan seed 1 pada 40 citra kelompok G1 menghasilkan
akurasi 42,50%, macro-F1 0,3108, dan MAE 0,7250 orang. Model memprediksi kelas 3 sekali dan prediksi itu keliru.
Artefak run tersimpan di `results/123450078/`. G4 disimpan untuk evaluasi akhir.

## Berikutnya
Bandingkan learning rate pada validasi. Uji ablation dropout dan weight decay secara terpisah.
